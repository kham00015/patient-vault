# LOINC order catalogs (local)

These files come from the free LOINC download (https://loinc.org/downloads/).

Used by Patient Vault order search:

- `LoincUniversalLabOrdersValueSet.csv` — common lab orders
- `ImagingDocumentCodes.csv` — imaging procedure codes

Do not commit redistributed LOINC content unless your LOINC license allows it.
Keep the CSVs on the machine that runs the app.

Source archive example: `Loinc_2.82.zip`
